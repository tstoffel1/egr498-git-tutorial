# Version control and git

## Open these for the class demonstration

1. Open **slides/version-control-and-git.pdf** for the presentation.
2. Open **DEMO-STEPS.txt** for your teaching sequence.
3. Open **PROJECT.md** in a text editor with autosave off for the save/commit example.
4. Open **rro_demo.py** in your Python editor for the code examples.
5. In GitHub Desktop select **egr498-git-tutorial** and **demo**.

From this folder, run:

```text
python3 rro_demo.py
```

On Windows, use `py -3 rro_demo.py` if needed. The program prints robot messages and needs no Raspberry Pi hardware or extra packages.
